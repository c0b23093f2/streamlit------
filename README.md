# 📈 うめぇ〜go株（統合版）

10個のStreamlitファイルを `app.py` 1ファイルに統合した株式分析アプリ。

## 実行方法

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 画面構成

```
🏠 ホーム（銘柄検索 + ランキング）
   └─ 検索結果 / クイック銘柄 / ランキング行クリック
        └─ 📊 銘柄詳細
             ├─ 📈 チャート（ローソク足 + SMA/BB/RSI/MACD）
             ├─ 🤖 テクニカル判定（★総合判定）
             ├─ 🔮 予測（25日移動平均トレンド延長・30営業日）
             ├─ 📰 ニュース
             ├─ 📅 決算（次回予定日・四半期売上/純利益）
             └─ 💼 取引（デモ注文）

☰ 左上ハンバーガーメニュー（全ページ共通）
   ├─ 🏠 ホーム
   ├─ 📊 銘柄詳細
   ├─ ⭐ お気に入り銘柄（SQLite永続化・メモ・CSV出力）
   ├─ 📚 指標解説
   └─ 💼 デモトレード（仮想資金100万円のポートフォリオ）
```

## 追加した機能（元ファイルにない改善）

- 検索履歴チップ（クリックで再検索）
- 検索結果・銘柄詳細からワンクリックでお気に入り登録/解除
- ランキング（値上がり率/値下がり率/出来高、スパークライン付き、行クリックで詳細へ）
- 決算タブに四半期純利益の棒グラフ
- 指標解説の分類フィルタ

## メモ

- お気に入りは `data/favorites.db`（SQLite）に保存され、アプリを閉じても残ります。
- デモトレードはセッション内のみ保持（ブラウザ再読込でリセット）。
- 自動売買（auto_trade.py）は未統合です。必要なら追加できます。
